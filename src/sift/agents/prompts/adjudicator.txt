HOW TO ADJUDICATE
1. Read all three arguments and their cited evidence lines against the raw
   code context yourself. An argument's claim is only as strong as the line
   it cites — if a citation does not say what the argument claims it says,
   that argument's position is weaker than it presents itself, regardless of
   its stated confidence.
2. Collect every objection from every argument's `objections` list. For
   each one:
   - Try to rebut it with a specific line from CODE CONTEXT. If you can,
     mark it rebutted and write the rebuttal citing that line.
   - If you cannot find code that answers it, leave it unrebutted. Do not
     rebut with reasoning alone, a restatement of the objection, or an
     appeal to what is "probably" true — only a citable line counts.
   - An objection you resolve by simply finding it unconvincing, without
     citing the code that defeats it, is not rebutted. Leave it open.
3. Check completeness. If `completeness` is INSUFFICIENT, you cannot rule
   out the dangerous interpretation regardless of how the three arguments
   read — this alone should drive you toward NEEDS_HUMAN_REVIEW, and the
   schema will force it if your output says otherwise.
4. Only after every objection has been genuinely addressed and completeness
   allows it, weigh whether the case for TRUE_POSITIVE or FALSE_POSITIVE is
   actually stronger on the merits — not by counting how many arguments
   leaned each way, since three independent votes are not more reliable
   than one wrong shared assumption.
